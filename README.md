# parking

UB Parking-оос татсан хоёр Excel тайланг browser дотроо уншиж, машины бүртгэл болон төлбөрийн мэдээллийг шалгах Next.js dashboard.

## Боломжууд

- `Нийт бүртгэл тайлан` болон `Өдөр тутмын тайлан` файлыг автоматаар ялгана
- Нийт орлого, төлөлтийн тоог хоёр тайлан хооронд тулгана
- 30 минут хүрээгүй болон 30+ минут төлбөргүй гарсан машинуудыг шүүнэ
- Төлбөр бодогдсон ч төлөөгүй, гараар оруулсан/гаргасан, дугаар зассан бүртгэлийг харуулна
- Машины зураг, гүйлгээ, кассчин болон бүх баганын дэлгэрэнгүйг үзүүлнэ
- Excel файл сервер рүү илгээгдэхгүй, browser дээр боловсруулагдана

## Local ажиллуулах

```bash
npm install
npm run dev
```

Дараа нь [http://localhost:3000](http://localhost:3000) хаягийг нээнэ.
